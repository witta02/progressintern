# 🎓 Internship Management System

ระบบบริหารจัดการการฝึกงาน สำหรับเชื่อมโยง นักศึกษา สถานประกอบการ และสถานศึกษา

## 📁 Project Structure

This is a combined repository containing both Backend (Go) and Frontend (Angular).

```
.
├── BackEnd/        # Go API Server
└── frontend/       # Angular Web Application
```

---

## 🚀 Quick Start

### Backend (Go)
1. `cd BackEnd`
2. Configure `.env`
3. `go run cmd/server/main.go`

### Frontend (Angular)
1. `cd frontend`
2. `npm install`
3. `npm start`
